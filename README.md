## 📧 EmailJS Integration

The contact form is integrated with **EmailJS**, allowing visitors to send project inquiries directly from the portfolio website.

When a visitor submits the contact form, the following information is sent directly to the portfolio owner's email:

- Name
- Email Address
- Phone Number
- Company
- Project Type
- Budget
- Message

The EmailJS integration allows the website to send emails without requiring a separate backend server.

### Email Flow

```text
Visitor fills Contact Form
          ↓
Clicks "Send Message"
          ↓
EmailJS Processes Request
          ↓
Portfolio Owner Receives Email
          ↓
Reply directly to Visitor
